# Examples

- `arcadedb/statefulset-before.yaml` and `statefulset-after.yaml`: `package/src/main/config/arcadedb-statefulset.yaml` from [ArcadeDB](https://github.com/ArcadeData/arcadedb) at commit `bf2a46b` (the base of PR 6851) and at the PR's merge commit `45e9dd7`, unchanged, under the Apache License 2.0 in `arcadedb/LICENSE`.
- `pitfalls/broken.yaml` and `pitfalls/fixed.yaml`: written for this repository, one container field for each kind of finding, and the same app fixed.

Run them with `make demo`, or see the README for the commands and their output.
