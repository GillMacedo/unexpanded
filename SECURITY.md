# Security

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/GillMacedo/unexpanded/security/advisories/new), not in a public issue.

unexpanded only reads the files it's given and opens no network connection. A wrong finding, or a broken reference it misses, is a normal bug. If a crafted manifest can make it do something other than read and report, report that privately. unexpanded is a diagnostic aid and doesn't enforce anything.
